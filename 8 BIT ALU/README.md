# 8-bit ALU in Verilog

## Overview
This project implements an 8-bit Arithmetic Logic Unit (ALU) in Verilog HDL. The ALU performs arithmetic and logical operations based on a control signal and is verified using a comprehensive testbench with simulation waveforms.

## Features
- 8-bit Addition
- 8-bit Subtraction
- Bitwise AND
- Bitwise OR
- Bitwise XOR
- Bitwise NOT
- Left Shift
- Right Shift

## Tools Used
- Verilog HDL
- ModelSim / Vivado / Icarus Verilog
- GTKWave (for waveform visualization)
